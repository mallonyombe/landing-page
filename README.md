# EL-ROI’S SPA — v4 final demo direction

A photo-led, mobile-first digital spa menu designed for QR-code discovery.

## Product model
QR poster/window → mobile site → visual service discovery → treatment selection → WhatsApp appointment.

This is intentionally a static front-end. No backend, authentication, database or booking engine is required for the current client scope.

## What v4 closes
- Complete demo content and pricing in ZAR.
- Real EN/PT language switching with persisted preference.
- Functional WhatsApp booking links with prefilled message.
- Demo location + Google Maps directions.
- Instagram and TikTok links.
- Opening hours and appointment requirement.
- Pedicure safety notice.
- Pregnancy / treatment comfort notice.
- Wig-care clarification: natural hair is not currently washed.
- Mobile sticky WhatsApp CTA.
- Scroll-linked service navigation.
- Reduced-motion support.
- Semantic headings, skip link, alt text and keyboard-friendly controls.
- SEO/meta foundation.

## Photography
Current imagery uses external Unsplash prototype assets for art direction. Production should replace these with EL-ROI’S SPA-owned photography for brand authenticity and licensing control.

## Design principle
The services should be felt visually before they are read. The interface uses editorial typography, generous whitespace, large service photography, restrained motion and a persistent path to booking.

## Research basis
The direction was cross-checked against current beauty/spa web patterns: photography-led heroes, mobile-first service discovery, editorial layouts, clear conversion paths, authentic photography, restrained palettes and touch-friendly navigation.
